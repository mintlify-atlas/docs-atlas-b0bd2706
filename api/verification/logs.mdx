---
title: "GET /api/verify/logs — verification history"
description: "GET /api/verify/logs lists all verification scan records. Role-scoped: nurses see own scans, doctors see hospital logs without score, admins see all records."
---

Every verification scan — whether it results in a match or no match — creates a log entry. These entries record the operator, patient (if matched), score, geolocation, and timestamp. Visibility is automatically filtered based on the requesting user's role.

## List verification logs

```bash
GET /api/verify/logs
Authorization: Bearer {token}
```

### Role-based visibility

| Role | Records returned |
|------|-----------------|
| `super_admin` | All hospitals (filter by `hospital_id`) |
| `admin` | All logs for own hospital |
| `doctor` | All logs for own hospital; `score` field hidden |
| `nurse` | Only their own logs (where `operator_id` = their user ID) |

### Query parameters

<ParamField query="patient_id" type="integer">
  Filter by patient.
</ParamField>

<ParamField query="operator_id" type="integer">
  Filter by operator (admin/super_admin only).
</ParamField>

<ParamField query="status" type="string">
  Filter by result: `matched` or `no_match`.
</ParamField>

<ParamField query="per_page" type="integer">
  Results per page. Defaults to `20`.
</ParamField>

### Example request

```bash
curl "https://api.hospital.example/api/verify/logs?status=matched&per_page=10" \
  -H "Authorization: Bearer {token}" \
  -H "Accept: application/json"
```

## Retrieve a single log

```bash
GET /api/verify/logs/{log}
Authorization: Bearer {token}
```

Returns the full log record including patient date of birth and JMBG, operator name, and fingerprint quality score.

### Response — 200 OK

```json
{
  "log": {
    "id": 214,
    "score": 0.68,
    "status": "matched",
    "gps_latitude": 3.1478,
    "gps_longitude": 101.6953,
    "wifi_ssid": "HospitalNet-Staff",
    "created_at": "2026-04-30T10:45:00.000000Z",
    "patient": {
      "id": 55,
      "full_name": "Ahmad bin Yusof",
      "date_of_birth": "1978-04-12",
      "jmbg": "78041211223344"
    },
    "operator": { "id": 7, "name": "Sarah Johnson" },
    "fingerprint": { "id": 23, "finger_position": "right_index", "quality_score": 0.72 }
  }
}
```

<Note>
  Doctors do not see the `score` field in log responses. This field is hidden automatically for the `doctor` role.
</Note>
