The system is configured through environment variables. The Laravel backend reads from `laravel/.env` and the Python service uses environment variables passed at process startup.

## Laravel backend

Copy `laravel/.env.example` as your starting point. The table below covers all variables relevant to the Biometric Patient ID System.

### Application

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `APP_NAME` | Yes | Application name shown in logs | `BiometricPatientID` |
| `APP_ENV` | Yes | `local`, `staging`, or `production` | `production` |
| `APP_DEBUG` | Yes | Enable debug output — must be `false` in production | `false` |
| `APP_URL` | Yes | Public base URL of the Laravel app | `https://api.hospital.example` |
| `APP_KEY` | Yes | 32-byte encryption key, generated by `php artisan key:generate` | `base64:...` |

### Database

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `DB_CONNECTION` | Yes | Database driver | `mysql` |
| `DB_HOST` | Yes | MySQL server hostname | `127.0.0.1` |
| `DB_PORT` | Yes | MySQL port | `3306` |
| `DB_DATABASE` | Yes | Database name | `biometric_health` |
| `DB_USERNAME` | Yes | Database user | `biometric_user` |
| `DB_PASSWORD` | Yes | Database password | — |

### Fingerprint processing service

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `FINGERPRINT_SERVICE_URL` | Yes | Base URL of the Python FastAPI microservice | `http://127.0.0.1:5001` |

<Warning>
  The Python service must be running and reachable at this URL before the Laravel backend will accept fingerprint enrollment or verification requests. A 503 response from the API indicates the service is unavailable.
</Warning>

### Sanctum authentication

| Variable | Required | Description | Default |
|----------|----------|-------------|---------|
| `SANCTUM_STATEFUL_DOMAINS` | No | Domains allowed stateful authentication | — |
| `SESSION_LIFETIME` | No | Session lifetime in minutes | `120` |

Tokens issued by `POST /api/auth/login` expire after **8 hours** (hardcoded in `AuthController`). There is no configuration variable for token TTL in the current release.

### Cache and queue

| Variable | Description |
|----------|-------------|
| `CACHE_STORE` | Cache driver (`file`, `redis`, `database`) |
| `QUEUE_CONNECTION` | Queue driver (`sync`, `database`, `redis`) |

## Python service

The Python service does not use a `.env` file. Pass configuration as environment variables when starting the process.

| Variable | Description | Default |
|----------|-------------|---------|
| `HOST` | Bind address (passed via `uvicorn` `--host` flag) | `127.0.0.1` |
| `PORT` | Bind port (passed via `uvicorn` `--port` flag) | `5001` |

The service has no database connection and no persistent storage — all state lives in the Laravel MySQL database.

## Mobile app

The Flutter app has one configuration point: the API base URL, which is hardcoded in `lib/services/auth_service.dart`:

```dart lib/services/auth_service.dart
static const String _baseUrl = 'http://172.20.10.14:8000/api';
```

Update this constant to point to your Laravel server's IP address or hostname before building the app for deployment.

<Tip>
  For a more flexible setup, move the base URL to a build-time environment variable using `--dart-define` and read it with `const String.fromEnvironment('API_BASE_URL')`.
</Tip>
